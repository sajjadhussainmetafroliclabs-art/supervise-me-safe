Complete UI Design Prompt (Figma / AI)

Design a modern mobile application called "Supportive Steps" for counseling students and licensed associates to anonymously review clinical supervisors. Use a calming mental-health inspired aesthetic with Sage Green (#4F6B5A), Soft Sage (#8A9B84), Warm Beige (#D7C3A0), and Off-White (#F8F7F4). Create clean, minimal, professional UI screens with rounded cards, soft shadows, elegant spacing, Poppins headings and Inter body text. Include Splash Screen, Onboarding, Authentication, Role Selection, Verification, Terms & Consent, Pending Approval, Dashboard, Supervisor Search, Supervisor Profile, Anonymous Review Submission, Notifications, Profile, and Settings. Focus on trust, anonymity, professionalism, accessibility, and emotional safety. Use modern 2025 mobile UX patterns with bottom navigation, card-based layouts, subtle illustrations, and a premium healthcare-tech appearance.
